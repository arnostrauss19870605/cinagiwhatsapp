How to: from a new template to answers in the prize draw ShowHide

1. Write and submit

  1. Click New template. Give it a name for the team and a Meta name like launch_q1_exercise.
  2. Category is Marketing for anything promotional, including a prize draw. Meta rejects a Utility template that reads like marketing.
  3. Write the message. Start with Hi {% templatetag openvariable %}first_name{% templatetag closevariable %}, so each person is greeted by name. Keep the footer "Reply AGENT any time to talk to a person."
  4. For a question, add up to three reply buttons with the answers, each under 25 characters.
  5. Save draft, check the placeholders section, then Send to Meta for approval.

2. Wait for approval

  1. The status on this page updates by itself. Approval usually takes minutes to a few hours.
  2. If it says Rejected, the reason is shown under the status. Open the draft, click New version, fix it and submit again.
  3. Approved templates can be changed only by making a new version. The old one keeps working until the new one is approved.
  4. Send yourself a test first: put your own number in a small audience and send to that before the real list.

3. Ask it, and count the answers

  1. Open Questions and click New question. Pick the approved template.
  2. Give each button a short code and a score, tick Answering earns a prize-draw entry, and optionally write a thank-you reply.
  3. Open Bulk send, choose the template and the audience, and click Start sending.
  4. Taps appear on the question's results page within seconds. The Prize draw page keeps the running entries and draws the winner.
