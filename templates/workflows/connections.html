For whoever builds the receiving end

Each call is an HTTPS POST with a JSON body. Answer with any 2xx status within 10 seconds; anything else counts as failed (a 5xx or no answer is tried once more).

Check both headers before acting:

  • Authorization: Bearer <token>
  • X-Cinagi-Signature: sha256=<hex> — HMAC-SHA256 of the exact request body, keyed with the token.

The body looks like this:

{
  "event": "workflow.webhook",
  "sent_at": "2026-11-02T10:15:00+02:00",
  "workspace": "Cinagi Broker Support",
  "workflow": "Main workflow",
  "step": "Request policy documents",
  "conversation_id": "…",
  "contact": {
    "number": "+27721234567", "wa_id": "27721234567", "name": "Thabo Mokoena",
    "details": {"id_number": "8001015009087", "cell_number": "0721234567"}
  },
  "answers": {"Main_Menu": "Policy & Benefits", "last_answer": "0721234567"}
}

A JSON object sent back is remembered for later steps if the step names it.
